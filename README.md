A program that writes one line to `/output/entry.txt`: the text a
gamer sends the boss to get out of work during GTA 6 launch week —
fever plus a burst kitchen pipe, back tomorrow. Entered in make.fun's
"The Excuse That Almost Works" bounty.

## Run it

```sh
python3 main.py
```

The program writes the entry line to `/output/entry.txt` (108
characters, 20 words, one line, no trailing newline). Running it
again writes the exact same bytes.
